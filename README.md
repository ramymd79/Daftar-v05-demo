# دفتر التجريبي

نسخة عرض ثابتة من واجهات دفتر v0.5، ببيانات تشطيبات مصرية وهمية فقط.

الرابط: https://ramymd79.github.io/Daftar-v05-demo/

- للاستعراض والتعريف بالمنتج فقط، وليست خدمة محاسبة أو مكتبًا حقيقيًا.
- يمكن التنقل والبحث واستعراض أمثلة المشروعات والجهات والعهد والمستحقات والتقارير.
- الحفظ والاعتماد والصرف والمصادقة والصلاحيات الفعلية والنسخ الاحتياطي تحتاج خادمًا؛ لا تنفذها هذه النسخة.
- اختيار الدور توضيحي؛ لا توجد كلمات مرور أو حسابات حقيقية، ولا تُدخل بيانات حقيقية.
- نفس الأمثلة الاصطناعية ثابتة للجميع؛ لا بيانات عمل مشتركة أو مزامنة بين الأجهزة. اختيار الدور والمظهر محليان في المتصفح.
- هذا المستودع يحتوي ملفات العرض المبنية فقط، دون قاعدة بيانات أو مرفقات خاصة أو أسرار أو كود الخادم.
